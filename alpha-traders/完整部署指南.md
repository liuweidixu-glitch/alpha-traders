# Trading War Room 完整部署指南

## 第二步：MT5 EA 部署（核心引擎）

### 2.1 找到 MQL5 文件夹

1. 打开 MT5
2. 菜单栏点击 **文件 → 打开数据文件夹**
3. 进入 `MQL5 → Experts` 文件夹

### 2.2 放入 EA 文件

1. 把 `TradingWarRoom_EA.mq5` 复制到 `Experts` 文件夹里
2. 回到 MT5，按 `Ctrl+N` 打开导航器
3. 右键 **EA交易** → **刷新**
4. 看到 `TradingWarRoom_EA` 出现

### 2.3 编译 EA

1. 双击 `TradingWarRoom_EA` → 打开 MetaEditor
2. 按 **F7** 编译
3. 看到 `0 errors, 0 warnings` = 成功

### 2.4 开启算法交易

1. MT5 工具栏点击 **Algo Trading** 按钮（变绿色）
2. 或者：工具 → 选项 → EA交易 → 勾选：
   - ✅ 允许算法交易
   - ✅ 允许 WebRequest（后面桥接要用）

### 2.5 挂载 EA 到图表

1. 打开 **AUDUSDm H1** 图表（或其他你想交易的品种）
2. 把 `TradingWarRoom_EA` 拖到图表上
3. 弹出参数窗口，默认即可，点击 **确定**
4. 图表右上角出现 **笑脸** = 正常运行

**此时 EA 已经可以独立运行交易了！**

## 第三步：Google Apps Script 桥接部署（通信中枢）

这是网页端和 EA 之间的"中转站"。

### 3.1 创建 Apps Script 项目

1. 打开 [script.google.com](https://script.google.com)
2. 登录你的 Google 账号
3. 点击 **新建项目**
4. 把 `mt5/BridgeCode.gs` 的全部代码粘贴进去
5. 保存项目（随便取个名字，比如 `TradingWarRoomBridge`）

### 3.2 部署为 Web 应用

1. 点击右上角 **部署 → 新部署**
2. 选择类型：**Web 应用**
3. 填写：
   - **执行身份**：我
   - **谁可以访问**：任何人
4. 点击 **部署**
5. 第一次会要求授权 → 点击 **允许**（选择你的 Google 账号，一路点到底）
6. 部署成功后，复制 **Web 应用网址**（类似 `https://script.google.com/macros/s/xxxxx/exec`）

**⚠️ 这个网址非常重要，保存好！**

## 第四步：网页端部署（GitHub Pages，最推荐）

### 4.1 创建 GitHub 仓库

1. 打开 [github.com](https://github.com)
2. 登录 → 点击右上角 **+ → New repository**
3. 仓库名填 `trade`（或其他你喜欢的名字）
4. 点击 **Create repository**

### 4.2 上传项目文件

**方式 A（最简单）：直接网页上传**

1. 在新仓库页面点击 **uploading an existing file**
2. 把项目所有文件拖进去（index.html + css/ + js/ + img/）
3. 点击 **Commit changes**

**方式 B（命令行）：**

```bash
cd /path/to/alpha-traders
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/trade.git
git push -u origin main
```

### 4.3 开启 GitHub Pages

1. 打开仓库页面 → 点击 **设置**
2. 左侧菜单点 **Pages（页面）**
3. **源** 选 **从分支部署**
4. **分支** 选 **main** → 文件夹选 **/(root)**
5. 点 **保存**
6. 等 1~2 分钟，网页会显示你的地址：
   ```
   https://liuweidixu-glitch.github.io/alpha-traders/
   ```

**打开这个地址，就能看到 Trading War Room 网页端！**

## 第五步：连接所有东西

### 5.1 EA 端配置桥接

1. 在 MT5 图表上右键 EA → **属性**
2. 找到 **网页桥接** 参数分组
3. 填入：
   - `WebhookURL` = 你的 Apps Script 网址（第三步得到的）
   - `WebhookSecret` = `twr-secret`（默认即可，要和网页端一致）
   - `AllowRemoteControl` = `true`
   - `AcceptWebSignals` = `true`（如果你想接收网页 AI 信号）
   - `OnlyWebSignals` = `false`（EA 本地信号也能用）
4. 点击 **确定**

### 5.2 MT5 允许 WebRequest

1. MT5：工具 → 选项 → EA交易
2. 找到 **WebRequest 允许 URL 列表**
3. 添加两行：
   ```
   https://script.google.com
   https://script.googleusercontent.com
   ```
4. 点击 **确定**

### 5.3 网页端配置桥接

1. 打开你的网页（`https://你的用户名.github.io/trade/`）
2. 点击右下角 **⚙ SETTINGS（设置）**
3. 填写：
   - **Bot Bridge URL** = 你的 Apps Script 网址
   - **Bridge Secret** = `twr-secret`
   - 勾选 **发送 AI 信号到 EA**
4. 点击 **保存设置**

### 5.4 测试连接

1. 网页端点击 **连接**
2. 如果显示 **已连接** + 看到 EA 的余额、权益、持仓数据 = 成功！
3. 点击 **暂停** → 看 EA 是否停止开新单
4. 点击 **恢复** → EA 恢复正常

## 第六步：Telegram 机器人设置（可选，但强烈推荐）

让你通过手机接收交易提醒。

### 6.1 创建 Telegram Bot

1. 打开 Telegram，搜索 `@BotFather`
2. 发送 `/newbot`
3. 按提示设置名字（如 `MyTradeBot`）和用户名（如 `my_trade_bot`，必须以 bot 结尾）
4. 收到 **Bot Token**（类似 `8123456789:AAExxxxxxxxx`）

### 6.2 获取你的 Chat ID

1. 在 Telegram 搜索 `@userinfobot`
2. 发送 `/start`
3. 收到 **Chat ID**（类似 `123456789`）

### 6.3 网页端配置 Telegram

1. 打开网页 → ⚙ **SETTINGS**
2. 填写：
   - **Telegram Bot Token** = 上面复制的 Token
   - **Chat ID** = 上面复制的 Chat ID
3. 勾选 **开启 Telegram 通知**
4. 点击 **测试发送**
5. 你的 Telegram 收到测试消息 = 成功！

### 6.4 Telegram 会收到什么？

- 📊 每日开盘提醒
- 🚀 A+ 信号出现
- 💰 新订单开仓
- 🔴 订单止损/止盈
- ⚠️ 风控触发（日亏损上限、连败暂停）

## 第七步：启动运行

### 7.1 确认所有组件状态

| 组件 | 状态检查 |
|------|---------|
| **MT5 EA** | 图表右上角笑脸，Algo Trading 绿色 |
| **Apps Script** | 部署状态显示"已部署"，URL 可访问 |
| **网页端** | GitHub Pages 显示绿色勾，能正常打开 |
| **桥接连接** | 网页显示"已连接"，能看到 EA 实时数据 |

### 7.2 推荐参数配置（新手起步）

在 EA 参数里设置：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `ScalpMode` | `false` | 先跑波段模式（H1），更稳定 |
| `RiskPercent` | `1.5` | 每单 1.5% 风险 |
| `MaxPerTradeRiskPct` | `4.0` | 每单最高 4% |
| `MaxPortfolioRiskPct` | `6.0` | 总持仓风险不超过 6% |
| `MaxDailyLossPct` | `5.0` | 日亏损 5% 自动停止 |
| `MaxConsecLosses` | `4` | 连亏 4 单暂停 |
| `SignalMode` | `SIG_EA` | 先用 EA 本地信号 |
| `AcceptWebSignals` | `false` | 新手先别开网页信号 |
| `WebhookURL` | 你的 URL | 必须填，否则桥接不通 |

### 7.3 建议运行流程

**第 1~2 周：Demo 账户观察**
- 只开 1~2 个品种（建议 AUDUSD + EURUSD）
- 不开黄金（XAU 点差大，需要更大资金）
- 不开 BTC（最小手数风险高）
- 观察 EA 的出单频率、胜率、风控触发情况

**第 3~4 周：逐步加入网页功能**
- 打开网页端监控
- 尝试回测不同组合，看哪个 Agent 组合表现最好
- 开始让 KnowledgeBase 积累数据

**第 1 个月后：开启 AI 进化**
- 开启 `AcceptWebSignals`
- 让 Gemini Head Coach 自动优化组合
- 根据 KB 数据调整参数

## 常见问题

### Q1: EA 不交易怎么办？
- 检查图表右上角是否笑脸
- 检查 Algo Trading 是否绿色
- 检查 `MaxDailyLossPct` 或 `MaxConsecLosses` 是否已触发暂停
- 检查 `DiagSkipLog` 设为 true，看 Experts 日志找原因

### Q2: 网页显示"未连接"？
- 检查 EA 的 `WebhookURL` 是否填对了
- 检查 MT5 的 WebRequest 白名单是否加了 Google 网址
- 检查 Apps Script 部署是否成功，URL 能否直接打开

### Q3: 网页端打不开？
- GitHub Pages 部署后需要等 1~2 分钟
- 检查仓库是否是 Public（Private 不行）
- 检查文件是否上传完整（index.html 必须在根目录）

### Q4: 需要 VPS 吗？
- **不需要**。如果你电脑 24 小时开机，直接跑就行。
- 如果要出门在外也能跑，可以用 VPS（如阿里云/腾讯云最低配，约 30 元/月）。

### Q5: 需要充钱吗？
- **全部免费**。Google Apps Script、GitHub Pages、Telegram Bot 都是免费的。
- 唯一可能花钱的是：你交易亏损（风险控制好了就没事）。
