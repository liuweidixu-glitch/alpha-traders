📰 新闻 Agent — 阅读方法
红色 = 高影响 (NFP, CPI, 利率决议) — 前后 30 分钟避免交易
黄色 = 中等影响 (PMI, Retail Sales)
绿色 = 低影响 (Speeches, minor data)
▲ = 利多消息 / ▼ = 利空消息 / ● = 中性
⚠️ 如果看到 "Event within 1h!" = 禁止下单！ 等新闻发布后再说
👑 COMMANDER PANEL
  • FINAL SIGNAL — ▲ BUY / ▼ SELL / ⏸ WAIT 伴随最佳 pair
  • Entry — 入场价, SL — Stop Loss, TP1/TP2 — Take Profit
  • R:R — Risk:Reward ratio (R:R 越高越划算)
  • Position — 建议 risking balance 的 %
  • Analyst Votes — ▲ = agent 投票 buy / ▼ = sell / — = neutral

  4. 查看 Commander Panel 找 Entry/SL/TP
  5. 检查 News Agent 1h 内没有 event
  6. 按照自己的风险管理下单
